# Integration examples

These C programs use only the public CrossDSD API. No third-party application is required.

| Directory | Purpose |
| --- | --- |
| `twistedwave` | Decode DSF to DXD |
| `twistedwave-encoder` | Encode DXD to DSD64 through DSD512, with an Enhanced option for DSD64 |
| `twistedwave-windows-decoder` | Decoding example intended for Windows |

Build with CMake, setting `CMAKE_PREFIX_PATH` to the installed SDK. Complete commands are provided in [GETTING_STARTED.md](../docs/GETTING_STARTED.md).
